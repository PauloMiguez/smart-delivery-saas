📦 TECNOLOGIAS:
   Backend: Node.js + Express + MySQL (TiDB Cloud)
   Frontend: React 18 + Vite + Styled Components
   Autenticação: JWT
   WebSocket: Socket.io
   Push Notifications: Web Push API (VAPID)
   Upload: Cloudinary

✅ FUNCIONALIDADES:
   - PWA completo com Service Worker
   - Notificações push específicas por dispositivo
   - Multi-tenant com isolamento de dados
   - Cardápio online com categorias
   - Checkout com agendamento
   - Acompanhamento de pedidos em tempo real
   - Painel administrativo completo
   - Dashboard com métricas
   - Desconto por forma de pagamento
   - Domínio personalizado
   - WhatsApp integrado
